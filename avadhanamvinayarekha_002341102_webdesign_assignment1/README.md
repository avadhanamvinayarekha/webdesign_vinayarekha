# vinayarekha_webdesign
# Blood Donation Website – Assignment 1

## Overview
This website is built to raise awareness about blood donation.  
It explains who can donate, shows upcoming drives, shares inspiring stories, and provides contact details.  
The project uses **HTML5** and an external **CSS stylesheet**, following semantic coding practices.

---

## Files
- `index.html` – Home page with hero section, reasons to donate, featured story, and video.
- `eligibility.html` – Eligibility rules with expandable tips.
- `drives.html` – Current blood inventory and upcoming drive schedule in tables.
- `stories.html` – Stories of people connected to blood donation.
- `media.html` – Audio and video resources on why to donate blood.
- `contact.html` – Contact form for sign-up and queries.
- `styles.css` – External stylesheet for all pages.

---

## HTML Tags Used with Short Descriptions

### Document Structure
- `<!DOCTYPE html>` – Defines the document as HTML5.  
- `<html>` – Root element for the page.  
- `<head>` – Holds metadata, title, styles, and favicon.  
- `<title>` – The page title shown in browser tab.  
- `<meta>` – Metadata like character set, viewport, and description.  
- `<link>` – Connects external CSS and favicon.  
- `<body>` – Contains all visible content.

### Semantic Layout
- `<header>` – Top section with logo/branding and navigation.  
- `<nav>` – Main navigation menu.  
- `<main>` – The main content of each page.  
- `<section>` – Groups related content into blocks.  
- `<article>` – Self-contained content like stories or reasons to donate.  
- `<aside>` – Extra or supporting info (e.g., donation tips).  
- `<footer>` – Bottom section with contact info and credits.

### Text & Headings
- `<h1>`–`<h3>` – Headings with different levels.  
- `<p>` – Paragraph of text.  
- `<strong>` – Highlights important text.  
- `<small>` – Shows side or minor text.  
- `<span>` – Inline container for styling or emphasis.

### Links & Buttons
- `<a>` – Hyperlinks, including normal links, `mailto:` (email), and `tel:` (phone).  
- `<button>` – Clickable action buttons.

### Lists
- `<ul>` – Unordered list.  
- `<li>` – List item inside a list.

### Tables
- `<table>` – Table container.  
- `<thead>` – Header row of the table.  
- `<tbody>` – Body rows of the table.  
- `<tr>` – Table row.  
- `<th>` – Table header cell.  
- `<td>` – Table data cell.

### Forms
- `<form>` – Form container for inputs.  
- `<label>` – Label text for form controls.  
- `<input>` – Input fields (`text`, `email`, `password`, `search`).  
- `<select>` – Drop-down list.  
- `<datalist>` – Autocomplete options for input fields.  
- `<option>` – Single choice inside select or datalist.

### Media
- `<figure>` – Groups image/video with caption.  
- `<figcaption>` – Caption for the figure.  
- `<img>` – Image element.  
- `<video>` – Embeds local video.  
- `<source>` – Provides media file source for video/audio.  
- `<audio>` – Embeds audio file.  
- `<iframe>` – Embeds YouTube video.

### Interactive / Extra
- `<details>` – Expandable/collapsible section.  
- `<summary>` – Visible heading for details block.

---

## CSS
- All styling is handled in `styles.css`.  
- No inline or internal styles were used.

---

## Conclusion
This project shows how different HTML5 tags can be combined to create a well-structured, accessible, and visually consistent multi-page website.  
Each element has been chosen to serve a clear purpose, both for meaning and for layout.
